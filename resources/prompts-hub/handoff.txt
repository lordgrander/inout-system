Production gotchas found:
- If production shows `Target class [old-enter.auth] does not exist`, `OldEnterAuth.php` or the `old-enter.auth` middleware alias in `app/Http/Kernel.php` is missing. Upload/register middleware and clear cache.
- If production shows parse error around `fn (...) => ...`, the server PHP is older than local PHP. Arrow functions were removed from the copied new/old controllers and replaced with normal callbacks.
- If old `/enter` save with upload fails with `Column 'enter_id' cannot be null`, the cause is `app/Models/beta_enter.php` now correctly sets `protected $primaryKey = 'enter_id'`, while old `EnterController` was still reading `$beta_enter->id`.
- Production hotfix applied in `app/Http/Controllers/EnterController.php`: replace `$enter_id = $beta_enter->id;` with `$enter_id = $beta_enter->enter_id;` in the old `/enter` create and draft create paths.
- This hotfix is intentionally narrow because old production is still active during migration. Do not refactor old `/enter`; touch only the broken path unless the user explicitly asks.
